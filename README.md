
# SysInfo Bash Script

This is an educational bash script that collects basic system information.  
*(Это учебный bash-скрипт, который собирает базовую системную информацию.)*

## 🚀 Features / Что собирает скрипт:
- Hostname and IP address *(Имя хоста и IP-адрес)*
- System Uptime *(Время работы системы)*
- List of regular users (UID >= 1000) *(Список обычных пользователей)*
- Top-5 processes by memory usage *(Топ-5 процессов по потреблению RAM)*
- Number of failed login attempts *(Количество неудачных попыток входа)*

## 🛠️ How to run / Как запустить:

1. Download the script *(Скачайте скрипт)*:
   ```bash
   wget https://raw.githubusercontent.com/WARION898/bash-sysinfo-project/main/sysinfo.sh
   ```

2. Make it executable *(Сделайте его исполняемым)*:
   ```bash
   chmod +x sysinfo.sh
   ```

3. Run the script *(Запустите)*:
   ```bash
   ./sysinfo.sh
   ```
